# Bonnie Blue's Mansion Escape (VR) A short first-person VR horror escape game made in Unity. ## Goal You wake up inside Bonnie Blue's mansion. Collect **3 keys** and reach the front door while being hunted by aggressive male AI enemies. ## Features - Full VR movement (XR Interaction Toolkit) - NavMesh AI hunters that chase and attack on sight - Key collection system - Win / Lose conditions - Everything in a **single C# file** for easy setup ## Requirements - Unity 2022.3 LTS or newer - XR Interaction Toolkit - Any OpenXR headset (Meta Quest, Valve Index, etc.) ## Quick Setup 1. Create a new Unity 3D (URP) project 2. Install **XR Interaction Toolkit** via Package Manager 3. Create an empty GameObject → add the `BonnieBlueMansionEscape` component 4. Set up XR Origin as the Player (add `VRPlayerController` + `PlayerHealth` + CharacterController + tag it **"Player"**) 5. Create hunters → add `NavMeshAgent` + `HunterAI` 6. Create keys → add XR Grab Interactable and link the Select Entered event to `KeyPickup.OnSelectEntered` 7. Create the exit door → add `ExitDoor` component 8. Bake a NavMesh on the floor 9. Assign the Exit Door and UI screens in the GameManager ## Controls - Left stick → Move - Sprint button (configurable) - Grip / Trigger → Grab keys ## License Free to use and modify.
